# Data contract: `web/data/*.json`

All files are UTF-8 JSON produced by `pipeline/export.py` and read by `web/app.js`.
Dates are `YYYY-MM-DD` (Asia/Taipei). Timestamps are ISO-8601 with offset.
Country keys are **ISO 3166-1 alpha-2, upper case**.

## Level codes

| level | zh | en | instruction zh | instruction en | colour (dark) | colour (light) |
|-------|----|----|----|----|----|----|
| 3 | 第三級：警告（Warning） | Level 3: Warning | 避免至當地所有非必要旅遊 | Avoid all non-essential travel | `#ff3b5c` | `#b3123a` |
| 2 | 第二級：警示（Alert） | Level 2: Alert | 對當地採取加強防護 | Practice enhanced precautions | `#ffb020` | `#d97a00` |
| 1 | 第一級：注意（Watch） | Level 1: Watch | 提醒遵守當地的一般預防措施 | Practice usual precautions | `#19ff8a` | `#1f8f5a` |
| 0 | 目前無針對性建議 | No specific advisory | — | — | `#0f1f17` | `#ece9d8` |

## `alerts.json`

```json
{
  "generated_at": "...",
  "levels": { "1": {"zh": "...", "en": "...", "instruction_zh": "...", "instruction_en": "..."}, "2": {}, "3": {} },
  "diseases": { "伊波拉病毒感染": {"zh": "伊波拉病毒感染", "en": "Ebola virus disease"} },
  "global": [
    { "disease": "新冠併發重症", "level": 1, "effective": "2023-11-01", "countries": 247 }
  ],
  "countries": {
    "CD": {
      "name_zh": "剛果民主共和國",
      "name_en": "Democratic Republic of the Congo",
      "max_level": 3,
      "alerts": [
        { "disease": "伊波拉病毒感染", "level": 3, "effective": "2026-05-27", "area_zh": "", "area_en": "", "iso_sub": "" },
        { "disease": "新型A型流感", "level": 2, "effective": "2026-09-01", "area_zh": "北京市", "area_en": "Beijing", "iso_sub": "CN-11" }
      ]
    }
  },
  "unmapped": [
    { "name_zh": "索馬利蘭共和國", "name_en": "Republic of Somaliland", "max_level": 1, "alerts": [ ] }
  ]
}
```

Rules:
- `alerts` sorted by level desc, then effective desc. Only **active** advisories (see ARCHITECTURE.md). Global advisories (same disease+level in ≥ 150 countries, e.g. 新冠併發重症 L1) are listed once in `global` with `applied_to_all: true` **and** applied to every country on the map except TW/AQ: each such row carries `"global": true` and counts toward `max_level`.
- `name_en` is the CSV `areaDesc_EN` cleaned (e.g. `Congo,Democratic Republic of the` → `Democratic Republic of the Congo` via `data/manual/country_names.json` override when present).
- `area_en` for sub-national rows comes from Gemini or `data/manual/areas.json`; fall back to `area_zh`.
- `diseases` contains every disease name appearing in `alerts.json` **and** `epidemics.json`.

## `epidemics.json`

```json
{
  "generated_at": "...",
  "window_start": "2024-10-08",
  "items": [
    {
      "id": "tBYXtWARDQm_4vJR_H_4Hw",
      "date": "2026-10-07",
      "disease_zh": "流行性腮腺炎",
      "disease_en": "Mumps",
      "headline_zh": "美國-流行性腮腺炎",
      "headline_en": "United States – Mumps",
      "summary_zh": "加州聖地牙哥州立大學 9 月累計 14 例，校方提供免費追加劑。",
      "summary_en": "San Diego State University reported 14 cases in September; boosters are being offered.",
      "description_zh": "原文…",
      "description_en": "Full translation…",
      "countries": ["US"],
      "area_zh": "美國",
      "area_en": "USA",
      "url": "https://www.cdc.gov.tw/TravelEpidemic/Detail/...",
      "ai": true
    }
  ],
  "overviews": {
    "CD": { "zh": "近兩年剛果民主共和國…（≤3 句）", "en": "Over the past two years…", "items": 23, "updated": "2026-10-08" }
  }
}
```

Rules:
- `items` sorted by `date` desc, limited to the last **2 years** from run date.
- `countries` = split of `ISO3166` by comma, trimmed, upper-cased; empty list for global/regional items. Items whose `areaDesc` starts with `全球` get `countries: []` and `global: true`.
- When Gemini is unavailable: `headline_en`/`summary_en`/`description_en` = zh text, `summary_zh` = first sentence of description, `ai: false`.
- `overviews` only for countries with ≥ 1 item; generated by Gemini from that country's items (title + summary list), zh & en.

## `flights.json`

```json
{
  "date": "2026-10-08",
  "fetched_at": "...",
  "source": "https://www.taoyuan-airport.com/flight_timetable?lang=en",
  "hub": { "iata": "TPE", "name_en": "Taiwan Taoyuan International Airport", "name_zh": "臺灣桃園國際機場", "lat": 25.0777, "lon": 121.233 },
  "routes": [
    { "iata": "NRT", "city_en": "Tokyo (Narita)", "city_zh": "東京(成田)", "country": "JP", "lat": 35.7647, "lon": 140.386,
      "departures": 14, "arrivals": 13, "airlines": ["CI", "BR", "JL"] }
  ],
  "totals": { "departures": 420, "arrivals": 415, "destinations": 98 }
}
```

Rules:
- One entry per airport (IATA). `country` from `airports.json`. Entries lacking coordinates are dropped but counted in `totals.unmatched`.
- If fetch fails, the previous day's `flights.json` is kept and `meta.sources.flights.ok=false`.

## `world.json`

TopoJSON (`world-atlas` 50m) with `objects.countries`; every geometry has `id` = ISO alpha-2 (string) and `properties.name` (English). Geometries without an alpha-2 keep their numeric id prefixed `n`. Built by `pipeline/build_geo.py` from `world-atlas` + `world-countries` (ccn3 → cca2).

## `airports.json`

```json
{ "NRT": { "name": "Narita International Airport", "city": "Tokyo", "country": "JP", "lat": 35.7647, "lon": 140.386 } }
```
From OpenFlights `airports.dat`, IATA-keyed, only airports with a 3-letter IATA code. Country converted to alpha-2 via `world-countries`.

## `countries.json`

```json
{ "JP": { "zh": "日本", "en": "Japan", "lat": 36.2, "lon": 138.25 } }
```
Name lookup for every ISO alpha-2 (zh from `world-countries` `translations.zho`, with `data/manual/country_names.json` override), centroid for label/arc placement.
